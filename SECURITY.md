# Security policy

I publish this repository as a static personal website and a standalone book page. There is no application backend or account system in the deployed site.

I keep the `main` branch as the supported version. If you find a security issue in the source, build scripts or deployment workflow, please email **kianzadaria@gmail.com** with a concise description and steps to reproduce it. Please avoid publishing an exploitable issue before I have had a reasonable chance to investigate it.

I do not promise a response time, but I will review reports and make a best effort to address valid issues.
